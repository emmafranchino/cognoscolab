# Rassereno: exam and anxiety frames in students and GPT-oss

Behavioural forma mentis networks (BFMNs) of high school, physics and psychology students and of
GPT-oss personas matched one-to-one to them. Everything under `out/` is regenerated by the notebooks
below. The formatted data, the samples and the result tables are committed; the plots and the pickled
networks (`*.pkl`) are not.

## Folders

```
rassereno/
  data/                      raw inputs (committed)
    data_2025.csv              Qualtrics export, survey of March–September 2025
    data_2026.csv              Qualtrics export, survey from 16 October 2025 (codes; the later
                               responses of the 29 October 2026 export are appended at the end)
    data_2026_2026-10-29_labels.csv   same survey with answer labels, reference for the codes
    participant_ids.csv        participant ID of each Qualtrics response (ResponseId)
    fall2024_data collection/  2024 psychology BSc data (Excel files) + notes on missing files
    data_2019/                 2019 experts and high school data (not used in this paper)
    gpt_oss_2026/              GPT-oss personas: personas.csv, generation_report.csv and one JSON
                               per persona (gpt_oss_<id>.json, with prompts and every attempt)
  notebooks/                 analysis notebooks (run order below)
  out/                       generated by the notebooks
    formatting/                cleaned data, one row per participant (and cue), committed
      all_students_2025/         every Qualtrics participant 2025–2026, with participant IDs
      psychology_BA_2024/        2024 psychology BSc students
      gpt_oss_2026/              GPT-oss answers in the same format as the humans
    splitted_dfs/              the samples of this paper, committed: all.csv (whole sample),
                               high_anx.csv and low_anx.csv (above / below the sample's MAS-IT median)
    analysis/                  network features, LaTeX tables, Jaccard results (committed) and plots
      concreteness/                  concreteness of every frame and its LaTeX tables (committed)
      bfmn/exam_anxiety_paper/          frame plots (filtered networks), not committed
      emo_flowers_bfmn/exam_anxiety_paper/  emotional flowers, not committed
```

Shared code lives in `src/` at the repository root (`config.py` holds the paths and the cue lists).

## Samples

| Sample | Source | IDs in `all_students_2025` / `psychology_BA_2024` |
|---|---|---|
| High school | northern licei (May 2025) + southern high schools (September 2026) | `liceo*`, `high_school_south_*` |
| Physics | University of Trento | `fisica_*`, `fisica_stem_*`, `fisica_unitn_*` |
| Psychology | BSc students 2024 (Set 4) + 2025 cohort (Set 5b) | `first_year_*`, `second_year_*`, `third_year_*`, `interfacce_*` |

Exclusion criterion: participants missing more than a third of their association and valence answers
are excluded (same rule for every group; responses that stopped before the association task count as
entirely missing). Only the 7 answer cells of each cue count (its valence, the three associations and
their valences), not the cue word itself. On the 2024 paper forms a 0 marks an unanswered cell, so a 0
(or a valence outside the 1–5 scale) is missing; other numbers given as associations are answers. For
STEM-group participants who came back for later sessions, only the first session is kept. The 2024
form saved as `.ods` (`LL_010.ods`, third year) is not read and is left out.

Participant IDs are fixed in `data/participant_ids.csv` (Qualtrics `ResponseId` -> `participant_id`), so
they don't depend on row order or on exclusions, and each GPT-oss persona keeps matching its student.
`data_extraction_qualtrics.ipynb` rebuilds the file with its ID rules only if it is missing; a response
that passes the exclusion rule without an ID stops the notebook, so new responses get an ID explicitly.

Each GPT-oss persona is named after its student (`gpt_oss_<human id>`). Networks are built on the 18
cue words shared by every cue set (`COMMON_CUES_RASSERENO` in `src/config.py`); *docente* (Set 5) and
*insegnante* (Set 4) are merged into one cue, also where they appear as associations (`CUE_SYNONYMS`).

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install -e .
```

`pip install -e .` makes `src/` importable from the notebooks. The spaCy models (`it_core_news_lg`,
`en_core_web_lg`) are installed by `requirements.txt`.

## Run order

1. `notebooks/data_extraction_2024.ipynb` → `out/formatting/psychology_BA_2024/`
2. `notebooks/data_extraction_qualtrics.ipynb` → `out/formatting/all_students_2025/`
3. GPT-oss answers → `out/formatting/gpt_oss_2026/`, rebuilt from the raw responses:
   ```bash
   python src/gpt_oss_data_generation.py collect --out rassereno/data/gpt_oss_2026
   ```
   (`personas` and `generate` are needed only to simulate new personas, see the docstrings of
   `src/gpt_oss_data_generation.py` and `src/gpt_oss_extra_personas.py`)
4. `notebooks/merge_and_split_datasets.ipynb` → `out/splitted_dfs/` (also reads the 2023 and 2024
   psychology cohorts in `math_anxiety_LLMs/out/formatting/`, used only for `all_psychology_students`)
5. `notebooks/bfmn_rassereno.ipynb` → network features, `all_bfmns.pkl`, frame plots and flowers
6. `notebooks/jaccard_similarity.ipynb` → exam–anxiety overlap and permutation tests
7. `notebooks/latex_tables_creation.ipynb`, from the section *Network feature tables* (the first part
   rebuilds the old cue-word summary and is not needed) → LaTeX tables in `out/analysis/`
8. `notebooks/concreteness_analysis.ipynb` → `out/analysis/concreteness/`: mean concreteness of each
   frame against a random baseline (Brysbaert et al. 2014 norms, translated and lemmatised, in
   `out/analysis/concreteness_dataset_lemmatized_*.csv`), and the LaTeX tables of the frames more / less
   concrete than random. It rebuilds the unfiltered networks itself, so it needs only step 4; new samples
   are added in its `NEW_SAMPLES`.

The other notebooks in `notebooks/` (STEM group, gender, free text, school intervention, 2019 data,
old GPT data) belong to other analyses and are not needed for this paper.
