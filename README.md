# Cognoscolab projects

## Scripts folder
In this folder you can find all the scripts used for the analysis (the same used across all projects). There are 4 files:
1. bfmn_free_associations.ipynb --> it creates behavioural forma mentis networks (from association and valence tasks)
2. correlogram.r --> it builds some correlogram (for the math_anxiety_LLMs project). I might change it/delete it
3. mas_it_analysis.ipynb --> it groups the mas-it results by factor and divide the sample in high and low anxiety population groups
4. tfmn_free_text.ipynb --> it builds textual forma mentis networks from the free text task

## Structure of each projects
### data
It containes the raw data of each sample group (e.g. raw data of 2023 humans). One can find multiple files, sotred in folders or a single file, depending on how th data was collected. 

### scripts
Here there is the code (divided into multiple scripts, base on the number of sample groups) that extracts the raw data and properly formats it. 

The formatted data will be exported in .csv files and stored in the folder "formatted" conained in the "out" folder. 

### out
Here all the outputs are stored:
- formatted: the formatted raw data is present (divided by sample gorups, e.g. 'gpt-3.5)
- analysis: here all the outputs generated by the analysis are store (e.g., fmnt, correlograms, emotional flowers, etc.). Also in this case there are subfolders for each sample group)
- splitted_dfs and mas_it_factors (present only in math_anxiety_LLMs): contain the results obtained by the script "mas_it_analysis". These files will be used to make the  final analysis (e.g., bfmn)

## math_anxiety_LLMs
This is the project related to a manuscript titled "Math anxiety and associative knowledge structure are entwined in psychology students but not in Large Language Models like GPT3.5 and GPT4-o". 

Here we extract and analysed the data of humans collected in 2024 and 2023, as well as data generated from LLMs (GPT-3.5 and GPT-4o).
